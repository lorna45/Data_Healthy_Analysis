# Diabetes Hospital Readmission Analysis

## Overview

SQL Server project analyzing diabetic patient hospital data to identify factors associated with hospital readmission.

## Objectives

* Analyze 30-day readmissions
* Calculate readmission rates
* Categorize diagnoses
* Analyze medication burden
* Analyze discharge dispositions
* Identify potential readmission risk factors

## Tools

* SQL Server
* SQL Server Management Studio (SSMS)

## Skills Demonstrated

SQL querying, data cleaning, `CASE`, `JOIN`, `GROUP BY`, `HAVING`, CTEs, aggregate functions, and window functions.
